# บันทึกหลังรอยแยก (Rift Ledger)

เกมจำลองชีวิตแบบ Text-based ในโลกฮันเตอร์ ดับเบิลคลิก `play.html` เพื่อเล่น

## แก้เกม

```bash
node build.mjs
```

```bash
node tools/sim.mjs 300
```

`build.mjs` สร้าง `play.html` ใหม่ ส่วน `tools/sim.mjs` เล่นอัตโนมัติหลาย Seed เพื่อหาบั๊กและดูสมดุล

## เพิ่มเนื้อหา (แก้ `src/data.js` ที่เดียว ไม่ต้องแตะระบบ)

| อยากเพิ่ม | ตาราง |
|---|---|
| อีเวนต์ / เนื้อเรื่องหลายตอน | `EVENTS` (ตอนต่อใช้ `next: [id, เดือน]`) |
| เควสหลักที่วนซ้ำ | `MAIN_H`, `CAREERS[].job` |
| คลาส / คลาสพิเศษ + เงื่อนไข | `CLASSES`, `SPECIALS` |
| พลังแฝง | `LATENTS` |
| อาวุธ / วัสดุ / คำขยาย | `WEAPONS`, `GRADES`, `AFFIX` |
| ธาตุ / รูปแบบวิชา | `ELEMENTS`, `FORMS` |
| อาชีพคนธรรมดา | `CAREERS` (`job` งานหลัก, `risk` โอกาสบาดเจ็บ, `d` คำบรรยาย) |
| อาชีพที่ครอบครัวเปิดให้ | `FAMILIES[].job` |
| เงินเดือน ค่าครองชีพ เกษียณ เกณฑ์เลื่อนขั้น | `CIV_ECON` |
| เควสต์เฉพาะคลาส/อาชีพ | แถว `EVENTS` ใส่ `who: [รหัส...]` |
| ภัยพิบัติในปฏิทิน | `WORLD` |
| ประโยคบรรยายซ้ำๆ (หมุนไม่ซ้ำกันติด) | `LINES` (ผลตัวเลือกอ้างแถวได้ด้วย `m: "@ชื่อแถว"`) |
| เอฟเฟกต์ตามจังหวะเกม | `src/presets.js` (ชื่อไฟล์จาก `pixelfx-main/src/fx`) |

ตัวเลือกอีเวนต์: `[ข้อความ, ค่าสเตตัส หรือ "fight" หรือ null, ความยาก, ผลเมื่อสำเร็จ, ผลเมื่อพลาด, ศัตรูเฉพาะ, who]` ช่อง `who` คือรหัสคลาสหรืออาชีพที่เห็นตัวเลือกนี้ (ไม่ใช้ศัตรูให้ใส่ `null` ในช่องศัตรู)

โบนัสพิเศษใน `m`: `mat` วัตถุดิบเพิ่ม, `brew` ปรุงยาเอง, `quest` ค่าจ้างงานหลัก, `safe` ลดบาดเจ็บ, `cxp` ผลงานอาชีพ คลาสและอาชีพใหม่ต้องมี `d` และ `job` อย่างน้อย 2 แถว รวมถึงอยู่ใน `who` อย่างน้อยหนึ่งแถว ไม่เช่นนั้น `tools/sim.mjs` จะแจ้งเตือน

เนื้อเรื่อง ตัวละคร และวิธีผูกเควสต์ต่อกัน อยู่ใน `STORY.md`

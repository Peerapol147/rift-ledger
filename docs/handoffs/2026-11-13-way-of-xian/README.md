# Handoff ให้ Claude: ตรวจแก้ความต่อเนื่องและพัฒนาความหลากหลาย

[เริ่มอ่านที่นี่](00-START-HERE.md) · [ผลรีวิวโค้ดล่าสุด](09-LATEST-CODE-REVIEW.md) · [แผนพัฒนา](04-IMPLEMENTATION-PLAN.md)

เจ้าของเกมขอให้นำรายงานและ handoff ขึ้น GitHub เพื่อให้ Claude พัฒนาต่อ แพ็กนี้เป็นเอกสารอย่างเดียว ยังไม่ได้แก้บั๊กหรือพัฒนาระบบใหม่

## ลำดับรับงาน

1. ตรวจ main ล่าสุดเทียบ commit `352f4a81ea29b9df647871dcf2d9c98d719950dd` แล้วแก้ 5 ข้อค้นพบในรายงานล่าสุดพร้อม regression tests
2. อ่านแบบและสัญญาโครงข้อมูล แล้วเริ่ม vertical slice สายประกันที่มีเส้นทางต่างกันและ NPC คนเดิม
3. ขยายตามแผนทีละเฟส พร้อมเก็บผลตรวจจริง ไม่ถือว่าการเพิ่มจำนวนตัวเลือกเท่ากับทำเรื่องแตกแขนงครบแล้ว

## หลักฐานและข้อจำกัด

รายงานล่าสุด: 246 tests ผ่าน, playtest/lifecheck 200 ชีวิตผ่านในขอบเขตที่เครื่องมือตรวจ, sim normal 1,000 ชีวิตผ่าน, build/artcheck/linelen ผ่าน และ browser 420px ที่อายุ 1/15/30 ไม่ล้นจอ ถึงอย่างนั้นยังพบเงื่อนไขเรื่องผิดบริบทที่ทดสอบทั่วไปไม่ครอบคลุม

เอกสาร 07 เป็น audit ฐานเก่า 198 tests; 09 เป็นผลตรวจเวอร์ชันใหม่ อย่าสับสนหรืออ้างว่า feature ที่เสนอไว้ใน 01–05 ทำเสร็จแล้ว

ไม่รวม HAR, cookie, token, แชทผู้เล่น หรือ source ของต้นแบบในชุดนี้ paths /workspace ที่ปรากฏเป็นบันทึกสถานที่ตรวจใน session เดิม ไม่ใช่สิ่งที่ Claude ต้องมีเพื่อเริ่มทำงาน

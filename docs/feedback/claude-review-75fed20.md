## P1 — ต้องแก้ก่อนแจก build

### 1. ภาพมอนสเตอร์มีไฟล์และเป็น own แล้ว แต่ runtime ไม่โหลด 10 ตัว

`src/monster-art.js` มี static ART registry แยกจาก MONSTERS. Chromium probe รอ image decode แล้ว
`monsterRaster(name, kind==='boss')` ยังได้ null สำหรับรายการต่อไปนี้:

- beast/ship-eating-vine
- beast/container-crab
- beast/sky-lure-bird
- spirit/offbeat-reflection
- spirit/you-from-the-other-side
- boss/evening-anchor
- boss/last-mayor
- boss/dry-lighthouse-keeper
- boss/last-tide-queen
- boss/salt-general

ผล: stage ใช้ fallback แทนภาพที่ส่งมา; CSS portrait ของ key ที่ขาดก็ไม่ถูกสร้าง.
บางตัวเป็นหนี้จากงานเดิมของ Codex ไม่ใช่ regression ที่ Claude สร้างทั้งหมด.

ให้ทำ: เพิ่ม import/ART entries ของทั้ง10ตัว หรือสร้าง registry จากข้อมูลกลางอย่างตรวจสอบได้.
อย่า apply `art/renderer-registration.patch` เดิมทั้งก้อนโดยไม่เทียบ — 4ตัวมี registration ใหม่แล้ว.
ตรวจทิศทางของรูปจริง; ใหม่หันซ้ายไม่ต้อง flip ส่วน legacy คงทิศเดิม.

เกณฑ์ผ่าน: browser decode ทุก MONSTERS ที่ own ต้องได้ raster, ขนาดตรง PNG, fly/boss ตรงข้อมูล;
สร้าง CSS portrait ได้; ตรวจภาพจริง ไม่ใช่แค่ตรวจว่าไฟล์มีอยู่.

### 2. ZIP ไม่ตรงกับ play.html ล่าสุด

อ่าน archive จริงแล้วพบ:
`ZipFile('downloads/rift-ledger-play.zip').read('rift-ledger/play.html') != Path('play.html').read_bytes()`.
หมายความว่าคนโหลด ZIP ไม่ได้ build เดียวกับที่กำลัง review แม้ play.html ในสาขาจะอัปเดตแล้ว.

ให้ทำ: หลัง merge/build ทุกครั้ง run `python tools/package-download.py` แล้วส่ง artifact ตัวเดียวกัน.
เกณฑ์ผ่าน: ZIP integrity ผ่าน และ HTML ภายใน byte-identical กับ build ล่าสุด; smoke-test ตัวที่แตกจาก ZIP.

## P2 — ภาพ/UX ยังขัดกับสิ่งที่เกมเล่า

### 3. ทารกแรกเกิดยังวางอยู่กลางถนน

หน้าเกิดจริงที่1280×800แสดงทารกบนพื้นหน้าตึก. `sceneOf(...,'kid')` คืน home แต่ stage home
ยังเป็น outdoor และวาดเมือง/พื้นถนน. เปลี่ยนรูปเป็นห่อตัวอย่างเดียวจึงยังไม่จบปัญหา.

ให้ทำ: ฉากห้อง/เตียงเด็กหรืออ้อมแขนผู้ปกครองสำหรับทารก และท่าพักที่ไม่เหมือนตั้งอยู่บนพื้นถนน.
เกณฑ์ผ่าน: ตรวจอายุ0/6/18/35เดือน ทั้งหญิงชาย บนมือถือและคอม; ไม่โดนฝน/หิมะในห้อง.

### 4. ฉากไม่รู้ว่าเรื่องเกิดที่ไหนและเวลาใด

ตัวอย่าง event infNight: "คืนหนึ่งไฟดับทั้งเมือง..." แต่ sceneOf คืน home เช่นเดิม;
SCENES.home เป็นท้องฟ้าสว่างและถูกจัด outdoor. ยังไม่มี scene override จากเวลา/สถานที่ของ event.

ให้ทำ: core ส่ง metadata ฉากที่เปิดเผยได้ (เช่น indoor/night/location) ให้ UI ใช้;
อย่า parse ข้อความภาษาไทยหรือเดาจากชื่อเรื่องทุกเฟรม. Codex ดูแลภาพ, Claude ดูแลข้อมูลเรื่อง.
เกณฑ์ผ่าน: เกิด/ไฟดับกลางคืน/โรงเรียน/โรงพยาบาล/เกต แสดงฉากตรงบริบทโดยไม่เผยข้อมูลลับ.

### 5. อายุ0ยังมีหัวข้อ "แผนเดือนนี้ · เลือกแผน" ทั้งที่เลือกไม่ได้

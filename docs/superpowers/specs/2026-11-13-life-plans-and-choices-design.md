# แผนชีวิตที่มีความหมาย และตัวเลือกที่มากขึ้น

สถานะ: เจ้าของเกมให้ทำ และมอบให้ผู้ออกแบบเลือกสิ่งที่มีประโยชน์จากเกมต้นแบบมาใช้เอง ("อิงสิ่งที่มีประโยชน์ ไม่ใช่ก็อป") · วันที่ 2026-11-13

## ทำไม

เจ้าของเกม: "ชอยส์น้อยมาก และไม่มีคำอธิบายการใช้ชีวิตเลยว่ามันจะส่งผลต่อชีวิตยังไง ... ถ้าเลือกแนวทางไหน เหตุการณ์ที่มักเพิ่มค่าพวกนั้นหรือเกี่ยวกับพวกนั้นจะโผล่มา"

| | เกมต้นแบบ (นับจากไฟล์) | เกมเรา |
|---|---|---|
| ตัวเลือกต่อเหตุการณ์ | เฉลี่ย 3.0 (83% มี 3 จาก 3,131 เหตุการณ์) | เฉลี่ย 2.05 (92% มี 2) |
| คำอธิบายแนวทาง | มี ("ปัญญาเติบโตเร็ว เหตุการณ์ด้านความรู้มาบ่อย") | ไม่มี |
| แนวทางดึงเหตุการณ์ | หลัก ×2 รอง ×1.4 | ไม่มีผล นอกจากเพิ่มค่าสถานะรายเดือน |
| บอกที่มาของเหตุการณ์ | บันทึกบอกว่ามาเพราะแนวทางไหน | ไม่มี |
| ของที่คว้าตอนขวบแรก | กำหนดแนวทางแรก | มีเหตุการณ์ แต่ให้แค่ค่าสถานะ |

กลไกที่ยืมมา: แนวทางหลัก/รอง ตัวคูณน้ำหนักเหตุการณ์ คำอธิบายแนวทาง ป้ายที่มาในบันทึก และของคว้าตอนขวบแรก เนื้อหา ชื่อ และข้อความเขียนใหม่ทั้งหมดในโลกของเรา

## เป้าหมาย

1. ทุกแผนมีคำอธิบายหนึ่งบรรทัด: ค่าไหนโต และเหตุการณ์สายไหนมาบ่อยขึ้น
2. แผนหลักทำให้เหตุการณ์สายเดียวกันถูกสุ่มได้ ×2.5 แผนรอง ×1.5 ส่วนโอกาสเกิดเหตุการณ์ต่อเดือนยังเท่าเดิม (เปลี่ยนแค่ว่าจะเป็นเรื่องไหน)
3. มีแผนรองตั้งแต่วัยรุ่น (13 ขึ้นไป) เลือกจากรายการแผนของวัยนั้นที่ไม่ใช่แผนหลัก และเลือก "ไม่มี" ได้
4. บันทึกต่อท้ายบรรทัดของเหตุการณ์ที่มาเพราะแผนว่า `· มาจากแผน <ชื่อแผน>`
5. ตัวเลือกแสดงป้ายผลสั้นๆ จากผลเมื่อสำเร็จ (`y`): ค่าสถานะ (↑/↓) เงิน (+/−) สุขภาพ สุขภาพจิต ชื่อเสียง ไม่บอกตัวนับลับ ไม่บอกผลตอนล้มเหลว
6. เหตุการณ์สุ่มที่มี 2 ตัวเลือก ได้ตัวเลือกที่ 3 ที่เป็นแนวทางต่างจากสองตัวเดิมจริง (มักใช้ค่าสถานะอีกตัว) เป้าเฉลี่ยของเหตุการณ์สุ่มทั้งหมด ≥ 2.8
7. ของที่คว้าตอนขวบแรก (`infToy`) กำหนดแผนเริ่มของวัยเด็ก: ดาบไม้ → ออกกำลัง หนังสือ → ตั้งใจเรียน เหรียญ → ช่วยงานบ้าน ผู้เล่นเปลี่ยนเองได้

**ไม่ทำ:** กิลด์และตระกูลที่ล็อกไว้ (ส่วนถัดไป) จังหวะชีวิต ×2 แผนในหอคอยหรือเกต

**ล้มเหลวแม้ผ่านเทสต์:** UI รกจนอ่านไม่ออกบนมือถือ, ตัวเลือกที่ 3 เป็นแค่ "ไม่ทำอะไร" ซ้ำๆ, ช่วงเงียบยาวขึ้น, ป้ายผลเผยความลับ (ข้อ 2 ของ spec หลัก: เกมไม่บอกความลับตรงๆ)

## สายของเหตุการณ์

สาย: `study` (เรียนรู้) · `body` (ร่างกาย) · `social` (ผู้คน) · `money` (เงินและงาน) · `mind` (จิตใจ) · `luck` (โชค) · `hunt` (ล่าเกต)

ระบบอ่านสายของเหตุการณ์เอง (ไม่ต้องติดป้ายทีละเรื่อง) และเหตุการณ์ใส่ `kinds: [...]` ทับได้ถ้าเดาผิด

- จากค่าสถานะในผลของตัวเลือกใดก็ได้: `int` → study · `str`, `agi` → body · `cha` → social · `wil` → mind · `luk` → luck
- จากผล: `gold > 0`, `jobXp` → money · `mind > 0` → mind
- จากหมวด (`tag`): งาน, เงิน → money · ความสัมพันธ์, ครอบครัว → social · ร่างกาย → body · การเรียน → study · เหตุการณ์ฮันเตอร์ (`hunter: true`) → hunt

## แผนและสาย

| วัย | แผน | สาย | คำอธิบาย (ร่าง) |
|---|---|---|---|
| 0–3 | เล่นกับพ่อแม่ | social | เสน่ห์โตทีละน้อย เรื่องกับคนในบ้านมาบ่อย |
| 0–3 | นอนกลางวัน | body | ร่างกายแข็งแรง เรื่องร่างกายมาบ่อย |
| 4–12 | วิ่งเล่น | body, luck | ว่องไวและโชคดีขึ้น เรื่องผจญภัยนอกบ้านมาบ่อย |
| 4–12 | ตั้งใจเรียน | study | ปัญญาโตเร็ว เรื่องโรงเรียนและหนังสือมาบ่อย |
| 4–12 | ออกกำลัง | body | กำลังโตเร็ว เรื่องกีฬาและร่างกายมาบ่อย |
| 4–12 | ช่วยงานบ้าน | mind, money | ใจนิ่งและได้ค่าขนม เรื่องเงินและครอบครัวมาบ่อย |
| 13–17 | อ่านหนังสือ / ฝึกร่างกาย / ทำงานพิเศษ / ออกไปกับเพื่อน | study / body / money / social | (เขียนตามแบบเดียวกัน) |
| 18–59 | ทำงาน / ฝึกฝน / ล่าเกต / เรียนเพิ่ม / พักผ่อน / สร้างสายสัมพันธ์ | money / body / hunt / study / mind / social | |
| 60+ | พักผ่อน / พบปะผู้คน / ทำงานต่อ | mind / social / money | |

## หน้าจอ (มือถือ 420px)

```
พ่อแม่เลี้ยงคุณแบบ               ← หรือ "แผนหลัก" ตั้งแต่ 4 ขวบ
[ เล่นกับพ่อแม่ ][ นอนกลางวัน ]
เสน่ห์โตทีละน้อย เรื่องกับคนในบ้านมาบ่อย      ← คำอธิบายของแผนที่เลือก (ตัวเล็ก สีจาง)
แผนรอง (ผลครึ่งหนึ่ง)              ← ตั้งแต่ 13 ปี
[ ไม่มี ][ อ่านหนังสือ ][ ทำงานพิเศษ ][ ออกไปกับเพื่อน ]
```
ตัวเลือกของเหตุการณ์: `[1] ชวนไปกินข้าวหลังซ้อมเสร็จ   เสน่ห์↑ จิต+` ป้ายผลอยู่ท้ายปุ่ม ตัวเล็ก

## ข้อจำกัด

- save เก่าไม่มี `focus2` ให้ถือว่าไม่มีแผนรอง
- seed เดิมต้องได้ชีวิตเดิม (`tools/sim.mjs` ตรวจ)
- บรรทัดใน `src/core`, `src/data` ไม่เกิน 120 ตัวอักษร
- ช่วงเงียบมัธยฐานใน playtest ไม่เกิน 2 ปี และ lifecheck ต้องสะอาด

## ตรวจรับ

- เทสต์: แผนหลัก study ทำให้สัดส่วนเหตุการณ์สาย study ที่ถูกสุ่มในวัยผู้ใหญ่สูงกว่าแผน work อย่างน้อย 1.8 เท่า (200 ชีวิต)
- เทสต์: ค่าเฉลี่ยตัวเลือกของเหตุการณ์สุ่ม ≥ 2.8 และไม่มีตัวเลือกที่ 3 ซ้ำข้อความกันเกิน 3 ครั้ง
- เทสต์: ป้ายผลไม่มีชื่อตัวนับ (`c`) และไม่มีผลตอนล้มเหลว
- ภาพหน้าจอมือถือ 420px ของแผงแผนและตัวเลือก

## คำตอบจากการตรวจของผู้ลงมือ (ผู้ออกแบบตัดสิน)

1. **สายของเหตุการณ์เมื่อมีตัวเลือกที่ 3:** สายมาจาก (ก) หมวดของเหตุการณ์ และ (ข) ค่าสถานะที่ปรากฏ **บ่อยที่สุด** ในผลของตัวเลือก (ถ้าเสมอกันเอาทุกตัวที่เสมอ) ตัวเลือกที่ 3 จึงไม่ทำให้เหตุการณ์มีสายเพิ่มตามไปด้วย ส่วน `kinds` ที่ใส่เองทับทุกอย่าง
2. **กติกาครั้งเดียวต่อชีวิตยังอยู่:** เทสต์วัดที่ "การสุ่มหนึ่งครั้ง ณ สภาพชีวิตเดียวกัน" คือสัดส่วนน้ำหนักของเหตุการณ์สาย study ในกองที่สุ่มได้ ต้องสูงกว่าตอนใช้แผน work อย่างน้อย 1.8 เท่า และเขียนเหตุการณ์ใหม่ให้สายที่บาง (study, mind, luck, hunt) อย่างน้อยสายละ 8 เรื่อง เพื่อให้แผนเหล่านั้นมีอะไรให้ดึงจริงตลอดชีวิต
3. **แผนรอง:** ได้ค่าสถานะรายเดือนครึ่งหนึ่ง และน้ำหนักเหตุการณ์ ×1.5 เท่านั้น ไม่ได้เงิน สุขภาพ หรือสุขภาพจิตจากแผน และไม่เปิดระบบที่ดู `s.focus` (ล่าเกต ฝึกฮันเตอร์ ค่าประสบการณ์งาน) แผน "ล่าเกต" และ "ทำงาน" เลือกเป็นแผนรองไม่ได้ เพราะทั้งคู่เป็นระบบเต็มตัว
4. **ตัวเลือกที่ 3:** เขียนให้ครบทุกเหตุการณ์สุ่มที่มี 2 ตัวเลือกในงานนี้ แบ่งเป็นชุดตามไฟล์ เป้าคือทุกเหตุการณ์ (ไม่ใช่แค่ค่าเฉลี่ย ≥ 2.8) ยกเว้นเหตุการณ์ที่มีตัวเลือกเดียวโดยตั้งใจ
5. **ถ้าไม่ได้คว้าของ:** ใช้กติกาเดิม (แผนแรกของวัย) ของที่คว้าตั้งค่าเฉพาะแผนหลักตอนครบ 4 ขวบครั้งเดียว เก็บเป็นตัวนับ `grab` (1 ดาบ 2 หนังสือ 3 เหรียญ) ไม่ต้องเพิ่มช่องใน save

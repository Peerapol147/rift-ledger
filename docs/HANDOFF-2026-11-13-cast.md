## 0. กติกาของเจ้าของเกม (ห้ามลืม)

- **ตอบเป็นภาษาไทยเสมอ** ภาษาง่าย ไม่ใช้ศัพท์เทคนิค เจ้าของไม่ใช่โปรแกรมเมอร์
- **ใช้ superpowers ทุกครั้งเองโดยไม่ต้องให้สั่ง** งานใหม่: brainstorming → เอกสารออกแบบ (+ builder check) → writing-plans →
  executing-plans (TDD ทุกข้อ, ledger, rulings) → reviewer ตัวใหม่ (model opus) ตรวจทั้ง branch → แก้ Critical/Important ด้วยเทสต์ที่ล้มก่อน
  → finishing-a-development-branch บั๊ก: systematic-debugging หาต้นเหตุก่อนแก้เสมอ
- **อิงเกมต้นแบบ Way of Xian ทุกครั้งเองโดยไม่ต้องให้สั่ง** (ข้อ 2) อิงกลไก ห้ามลอกโค้ด ข้อความ ชื่อ ภาพ
- เจ้าของ "เกลาทีละส่วนอย่างละเอียด ห้ามพลาด ไม่งั้นโครงพัง": ตรวจทุก gate ทุกครั้ง อย่าเชื่อเทสต์ที่ผ่านก่อนแก้ (ทำให้มันล้มให้ได้ก่อน)
- เจ้าของมอบการตัดสินใจราว 95% ("แก้ตามดุลยพินิจ") ถามเฉพาะเรื่องทิศทางใหญ่, การเผยแพร่สาธารณะ, งานภาพ
  ให้คำแนะนำพร้อมเหตุผล ไม่ใช่เมนู คัดค้านได้ถ้าคำขอจะทำให้เกมแย่
- **ประหยัด token**: เก็บ output ยาวลงไฟล์ แล้วอ่านแค่ส่วนท้าย
- ชื่อคลาส สกิล ไอเทม เป็นภาษาอังกฤษโดยตั้งใจ ห้ามเผยความลับใน UI (spec §11.1)
- ผู้เล่นใหม่เริ่มแบบออโต้ปิด (เจ้าของสั่ง: การเลือกเป็นของผู้เล่น ตามเกมต้นแบบ)
- อ่าน `CLAUDE.md` และ `AGENTS.md`: ภาพเป็นงานของ Codex (`art/`) โค้ดต้องการภาพใหม่ให้เพิ่มแถว `open` ใน `art/requests.json`
- branch ทำงาน: ตามที่ระบบกำหนดในห้องนั้น เปิด PR แล้ว merge เองได้เมื่อเจ้าของตกลง (เจ้าของพูด "รวมเลย" = merge)
  หลัง merge: ตั้ง branch ใหม่จาก main, `npm run build`, commit `play.html` + `downloads/`, ส่ง `play.html` ให้เจ้าของ

## 1. วิสัยทัศน์

ไม่มีตอนจบ โลกหมุนต่อ ตายแล้วคนอื่น (หรือลูกหลาน) เล่นต่อ ผู้เล่นไม่จำเป็นต้องเป็นตัวเอก ชีวิตยาว ต่างกันจริงจากการตัดสินใจ

## 6. บทเรียนจากห้องนี้ (กันพลาดซ้ำ)

- เทสต์ที่ผ่านก่อนแก้ = เทสต์ผิด แก้เทสต์ให้ล้มก่อน (เจอหลายครั้ง: offsetParent ของ fixed element, label เทียบผิด, element ถูกแทนที่)
- เรื่องใหม่ทุกเรื่องต้องตรวจ: คนตายห้ามพูด (needCast ครบทุกคนที่พูดในฉาก), เริ่มเฉพาะเมื่อ cast ยังอยู่, ข้อความเข้ากับทุกชีวิตที่ไปถึง
  (เพศ, ฮันเตอร์/คนธรรมดา, ประเทศ, อายุ), romance ต้อง trust 60 + อายุห่าง ≤ 5 ปี + โสดทั้งคู่ และวางหลังตัวเลือกเพื่อน
- ทุกครั้งที่เพิ่มเนื้อหาที่ให้ mind หรือแต่งงาน ให้รัน sim normal ดู mind (เคยขึ้นเป็น 80+ สองครั้งเพราะบอตแต่งงานง่าย)
- ความสุ่มของระบบใหม่ต้องใช้ stream ของตัวเอง ห้ามแตะ `pulse`/`world` (ข่าวเดิมของแต่ละ seed ต้องไม่เปลี่ยน)
